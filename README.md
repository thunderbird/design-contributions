# Thunderbird Design Hub
Welcome to the Thunderbird Design Hub! This is a central place for designers who want to help shape the look and feel of Thunderbird on various platforms. This repository acts as a stepping-stone that will direct you to the right project (web, desktop, mobile) and provide a clear workflow for contributing your design assets and ideas.

## Bolt: the Thunderbird design system
We use a shared component system to ensure visual consistency across our platforms.
* [Bolt Design System](https://bolt.thunderbird.net/)
* [Read about contributing to the Bolt design system here](https://bolt.thunderbird.net/8b179dbfd/p/20450a-contributing).

## How to get started
1. **Take a look at Bolt.** Start with the [Bolt foundations](https://bolt.thunderbird.net/8b179dbfd/p/41514d-foundations) to understand our design principles, color palettes, typography, icons, layout, and design tokens.
2. **Pick a project.** Review the issues in this repository. Each issue is a project that designs a concrete design task.
3. **Claim the issue**. In the issue, use the "Assign yourself" link to let the team you're working on it.
4. **Provide the desired design asset.** Using the appropriate tools (Figma, Penpot, etc.), create the design asset needed to satisfy the project's requirements and upload them to the issue.
